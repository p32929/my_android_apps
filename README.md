# my_android_apps

Download links for the Android apps we've built. Every APK lives in [one GitHub release](https://github.com/p32929/my_android_apps/releases/tag/all) — no Play Store, no installer, just the file.

## Why not Google Play?

We had a Google Play account, but Google terminated it without giving any explanation. We tried to contact them by email, by phone and every other way we could find — they never responded.

So, here we are.

## How to install an APK

Android blocks APKs from outside the Play Store by default. Download the file, tap it, and when Android asks, allow your browser or file manager to **install unknown apps**. You can switch that permission back off afterwards.
