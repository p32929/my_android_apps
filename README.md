# my_android_apps

Direct download links for some of our older Android apps. Every APK is in [one GitHub release](https://github.com/p32929/my_android_apps/releases/tag/all): no Play Store and no installer, just the file.

## Why not Google Play?

We had a Google Play account, but Google closed it without giving a reason. We tried to reach them by email, by phone and every other way we could find, and they never replied. So the apps live here instead.

## How to install an APK

1. Download the APK file and tap it.
2. Android blocks apps from outside the Play Store at first. When it asks, allow your browser or file manager to **install unknown apps**.
3. Tap **Install**. You can turn that permission off again afterwards.
